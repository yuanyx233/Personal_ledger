# 数据备份与恢复

在设置页下载完整 JSON，保存在自己控制的安全位置。CSV 用于查看和交换流水，不包含完整规则、导入历史和审计信息，不能替代 JSON 备份。

## 本地恢复

恢复目标必须是一个尚不存在的新目录，不能覆盖正在使用的数据库：

```bash
npm run db:restore -- --input ./ledger-export.json --persist-to /tmp/ledger-restored-d1
```

恢复会校验记录数、关联关系、分期组完整性和分币种汇总。当前 v5 备份保留账本仍读取的流水、分类、规则、预算、订阅历史和导入来源，但不再携带旧银行连接、账户或自动转账匹配记录。v4 及更早备份需要使用与其版本兼容的历史代码恢复，当前工具会明确拒绝，避免静默丢字段。

完整 JSON 限制为每个集合 50,000 条、总计 100,000 条、32 MiB。接近限制或恢复失败时，应先解决备份问题，不要覆盖最后一份已验证的备份。

## 故障处理

1. 保留原 D1；兼容时先回退应用版本。
2. 将备份恢复到独立本地目录，核对流水、分类规则与汇总。
3. 远端恢复、迁移或删除资源必须另行授权，不能把本地恢复命令改成直接覆盖线上数据库。

当前不需要自定义域名，也没有域名切换、银行重新连接或自动备份任务。
